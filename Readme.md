# 🎬 AI Movie Recommendation System

## 📌 Project Overview
This project is an **AI-based Movie Recommendation System** that suggests similar movies to users based on their preferences.  
It uses **collaborative filtering** and **cosine similarity** to recommend movies by analyzing user rating behavior.

The system is deployed as a **web application using Streamlit**, allowing users to interactively select a movie and get recommendations.

---

## 🎯 Objectives
- To build a recommendation system using real-world data
- To understand collaborative filtering techniques
- To implement cosine similarity for item-based recommendations
- To create an interactive web interface for recommendations

---

## 🧠 Technology Stack
- **Python**
- **Pandas & NumPy** – Data processing
- **Scikit-learn** – Cosine similarity
- **Streamlit** – Web application
- **MovieLens Dataset** – User ratings and movie details

---

## 📂 Dataset
The project uses the **MovieLens dataset**, which includes:
- `movies.csv` – Movie titles and genres
- `ratings.csv` – User ratings for movies

Dataset source: https://grouplens.org/datasets/movielens/
